# Memfit AI Overview

## What is Memfit AI?

Memfit AI is the open-source cybersecurity AI Agent orchestration framework of the **Yaklang** ecosystem, built on a **Recursive Dual-Engine Architecture** that combines strategic planning with tactical execution. It goes beyond simple chatbots: it ships **17 built-in focus modes** (deep research, fast execution, log analysis, and more) and **30+ pages of bilingual documentation** covering product docs and developer guides.

Under the hood, it rests on five pillars — Plan engine, ReAct engine, Tools & Forges, Knowledge/RAG, and Memory — that together deliver end-to-end security automation.

At its core, Memfit AI is a bridge between high-level human intent ("Audit this website") and low-level security operations (port scanning, vulnerability analysis). It achieves this by organically fusing:
*   **Determinism:** Structured planning for complex workflows.
*   **Flexibility:** Adaptive execution for dynamic environments.

## What Problems Does It Solve?

Traditional AI agents often face the "Single Paradigm Dilemma":
*   **Pure [ReAct](https://arxiv.org/abs/2210.03629) agents** (the reasoning-and-acting paradigm, Yao et al., 2022) easily get lost in long-horizon tasks, losing track of the original goal after many steps.
*   **Pure Plan-Execute agents** (the [Plan-and-Solve](https://arxiv.org/abs/2305.04091) paradigm, Wang et al., 2023) are too rigid, failing when the initial plan encounters unexpected obstacles or new information.

Memfit AI solves this by **recursively coupling** these two paradigms. It creates a plan, executes it, and if a sub-task becomes too complex, it recursively triggers a new planning phase. This allows it to handle tasks of arbitrary complexity while adapting to real-time feedback.

## Core Architecture: The 5 Pillars

Memfit AI is built around five key components that work in concert to deliver intelligent security capabilities.

| Pillar | Layer | Problem It Solves | Key Mechanisms |
|---|---|---|---|
| **Plan Engine** | Strategic | Complex security tasks cannot be done in a single step | Task tree generation, dependency management, recursive triggering |
| **ReAct Engine** | Tactical | The real world is non-deterministic | LoopEngine (OODA cycle), spin detection, self-reflection |
| **Tools & Forges** | Capability | AI models cannot touch the network or file system directly | Atomic tools, scenario-based Forges, Yaklang integration, MCP support |
| **Knowledge (RAG)** | Knowledge | LLMs lack private or up-to-date domain knowledge | Hybrid indexing (vector + keyword), agentic retrieval |
| **Memory** | Context | Standard sessions are stateless | C.O.R.E. P.A.C.T. scoring, vector-database persistence |

![Memfit AI Architecture Pillars](/img/memfit-5-pillars.jpg)

### 1. Plan Engine (Strategic Layer)

**The Problem:**
Complex security tasks (e.g., "Penetration Test") cannot be solved in a single step. They require a roadmap to ensure coverage and logical progression.

**The Solution:**
The Plan Engine acts as the strategist. It breaks down vague, top-level user goals into a structured **Task Tree**. It anticipates dependencies (e.g., "Scan ports before identifying services") and sets the execution order.

**Technical Architecture:**
*   **Task Tree Generation:** Deconstructs goals into hierarchical subtasks.
*   **Dependency Management:** Enforces temporal and logical execution order.
*   **Recursive Triggering:** Can be invoked by the ReAct engine when a subtask is too complex.

→ Further reading: [Recursive Dual-Engine Architecture](/docs/product/architecture/recursive-dual-engine), [Coordinator](/docs/product/features/coordinator)

### 2. ReAct Engine (Tactical Layer)

**The Problem:**
The real world is non-deterministic. A scanner might time out, a port might be closed, or a new vulnerability might be discovered. A static script cannot adapt to these changes.

**The Solution:**
The ReAct Engine handles the "Last Mile" of execution. For each atomic task in the plan, it spins up an independent loop of **Observation-Thought-Action**. It perceives the environment, reasons about the current state, and chooses the next best action.

**Technical Architecture:**
*   **LoopEngine:** Manages the OODA (Observe-Orient-Decide-Act) cycle.
*   **Spin Detection:** Prevents the agent from getting stuck in infinite loops (e.g., retrying a failed command endlessly).
*   **Self-Reflection:** Analyzes failures to generate correction plans automatically.

→ Further reading: [ReAct Loop](/docs/product/features/react-loop)

### 3. Tools & Forges (Capability Layer)

**The Problem:**
An AI model is a "Brain in a Vat"—it cannot touch the network or files system directly. It needs specialized interfaces to interact with the cybersecurity world.

**The Solution:**
*   **Tools:** Standardized atomic capabilities (e.g., `PortScan`, `ReadFile`, `HttpReq`).
*   **Forges:** Scenario-based "Blueprints" that package specific prompts, tools, and logic for a domain (e.g., "Java Code Audit Forge").

**Technical Architecture:**
*   **Yaklang Integration:** Natively leverages Yaklang's powerful security libraries.
*   **MCP Support:** Compatible with the [Model Context Protocol](https://modelcontextprotocol.io) for extensibility.
*   **Focus Mode:** Allows instantiating specialized environments for specific subtasks.

→ Further reading: [Tools & Forges](/docs/product/features/tools-forges)

### 4. Knowledge (RAG System)

**The Problem:**
LLMs have a training cutoff and lack private or highly specific domain knowledge (e.g., the latest CVE details or internal API docs).

**The Solution:**
The RAG ([Retrieval-Augmented Generation](https://arxiv.org/abs/2005.11401), Lewis et al., 2020) system serves as an active "external brain." It retrieves relevant documentation, past reports, and security knowledge to ground the AI's reasoning in fact.

**Technical Architecture:**
*   **Hybrid Indexing:** Combines vector search (semantic) with keyword search (precision).
*   **Agentic Retrieval:** The system actively decides *when* and *what* to search for, rather than just passively retrieving context.

→ Further reading: [Memory & RAG](/docs/product/features/memory-rag)

### 5. Memory (Context Layer)

**The Problem:**
Standard LLM sessions are stateless. The agent forgets what happened in the previous audit or what the user's preferences are, leading to repetitive mistakes.

**The Solution:**
The Memory System acts as an "Intelligent Hippocampus." It doesn't just store logs; it evaluates, scores, and indexes experiences. Successful strategies are remembered; failures are stored as "lessons learned."

**Technical Architecture:**
*   **C.O.R.E. P.A.C.T. Framework:** A scoring system to determine which memories are worth keeping (Connectivity, Relevance, Actionability, etc.).
*   **Vector Database:** Persists high-value memories for long-term recall across sessions.

→ Further reading: [Agentic Reliability Guarantees](/docs/product/architecture/reliability)

## FAQ

### What is Memfit AI?

Memfit AI is an open-source cybersecurity AI Agent orchestration framework from the Yaklang ecosystem, built on a recursive dual-engine (ReAct + Plan) architecture for security automation and code auditing.

### How does the recursive dual-engine work?

The Plan Engine handles strategy (task-tree generation), while the ReAct Engine handles tactical execution (Observation-Thought-Action loops). When a subtask becomes too complex, the ReAct Engine recursively triggers a new planning phase.

### Is Memfit AI free and open source?

Yes. Memfit AI is built on the open-source Yaklang engine, and the client can be downloaded for free from the [official downloads page](/downloads).

### Which operating systems does Memfit AI support?

macOS (Intel and Apple Silicon), Windows, and Linux are supported, with `.dmg`, `.exe`, and `.AppImage` installers respectively.

### What is Memfit AI's core architecture?

A five-pillar architecture: Plan Engine (strategic layer), ReAct Engine (tactical layer), Tools & Forges (capability layer), Knowledge/RAG (knowledge layer), and Memory (context layer), working in concert to deliver intelligent security capabilities.

### How is Memfit AI different from a traditional AI chatbot?

A chatbot can only converse; Memfit AI understands tasks, creates plans, invokes tools, and delivers results, with deep optimization for cybersecurity and code auditing scenarios.
